# 庄园物语（Manor Story）

> 基于 Unity6 的像素风农场模拟经营游戏毕业设计项目

[![Unity Version](https://img.shields.io/badge/Unity-6_2024.1-blue)](https://unity.com/) ![Language](https://img.shields.io/badge/Language-C#_9.0-green) ![Pipeline](https://img.shields.io/badge/RenderPipeline-URP-orange) ![Platform](https://img.shields.io/badge/Platform-Windows_PC-lightgrey)

## 📖 项目简介

《庄园物语》是一款轻量级像素风农场模拟经营游戏，参考《星露谷物语》《牧场物语》的核心玩法，采用**多场景拆分 + 模块化脚本架构**进行开发。实现农场开垦种植、背包资源管理、商店交易、昼夜循环、存档读档等完整经营闭环，针对PC端做性能优化，可作为独立游戏原型继续迭代开发。

本项目为重庆移通学院数字媒体技术专业毕业设计成果，旨在验证Unity6引擎在2D轻量级模拟经营游戏的开发方案，为同类独立游戏项目提供参考。

## ✨ 核心功能

1. **多场景联动系统**

- 五大核心场景：主菜单、农场主场景、室内场景、储物间副本、昼夜结算场景
- 异步加载场景，触发式场景切换，跨场景玩家位置、背包、作物数据同步
- 场景切换耗时≤1s，解决单场景开发复杂度高、维护困难的问题

1. **农场种植系统**

- 完整流程：开垦土地 → 播种 → 浇水加速生长 → 作物成熟 → 收获
- 多阶段作物生长，支持多种种子配置，枯萎校验，地块状态序列化存档

1. **资源与商业交易系统**

- 背包系统：资源分类存储、数量上限限制、UI实时刷新
- 货币管理、商店购买种子、售卖农作物，交易合法性校验（货币、背包空间校验）

1. **玩家与相机模块**

- 新输入系统实现WASD移动，8方向角色动画（待机、移动、锄地、浇水）
- 球形射线交互检测，F键交互触发
- 正交相机平滑跟随，边界限制，适配像素风格

1. **昼夜与氛围系统**

- 游戏内时间流逝，昼夜光照切换，天数递增结算
- BGM与多套音效管理（播种、收获、按钮、昼夜结算音效）

1. **数据持久化（存档读档）**

- JSON序列化 + PlayerPrefs混合存储方案
- 室内休息手动存档，游戏重启完整还原：天数、货币、背包、作物地块全部状态

## 🛠️ 技术栈

| 技术     | 说明                         |
| -------- | ---------------------------- |
| 引擎     | Unity 6 (2024.1 稳定版)      |
| 编程语言 | C# 9.0                       |
| 渲染管线 | URP 通用渲染管线             |
| 输入     | Unity New Input System 1.5.1 |
| UI       | UGUI                         |
| 地图     | Tilemap 瓦片地图             |
| 数据存储 | JsonUtility + PlayerPrefs    |
| 开发IDE  | Visual Studio 2022           |

**架构设计：四层分层模块化架构**

- 数据层：`DataManager`、数据序列化、全局数据缓存
- 业务逻辑层：GameManager、各个玩法模块脚本、场景调度
- 界面交互层：UGUI界面，UI交互与数据同步
- 渲染层：URP管线，动画、特效、光照渲染

> 设计模式：大量使用**单例模式**管理全局管理器；ScriptableObject配置种子、商品数据，方便配置修改与拓展。

## 💻 运行环境

### 最低配置

- CPU：Intel i3

- 内存：8GB

- 显卡：GTX1050

- 系统：Windows10/11 64位

  > 运行帧率≥60FPS，内存占用≤400MB

### 推荐配置

- CPU：Intel i5‑12400F

- 内存：16GB DDR4

- 显卡：RTX3060

  > 运行帧率90‑100FPS，启动时间≤1.5s

## 🎮 操作说明

| 按键      | 功能                       |
| --------- | -------------------------- |
| W A S D   | 角色移动                   |
| F         | 交互（休息、商店、收获等） |
| 数字键1‑4 | 快捷切换工具               |
| 鼠标点击  | 播种、耕地等地块操作       |

## 📂 项目目录简要说明

```
Assets
├── Scenes                 # 五大游戏场景资源
│   ├── MainMenu.unity     # 主菜单
│   ├── Main.unity         # 农场主场景
│   ├── Indoors.unity      # 室内场景
│   ├── Indoors‑Copy.unity # 储物间副本场景
│   └── DayEnd.unity       # 昼夜结算场景
├── Scripts
│   ├── GlobalManager      # 全局单例脚本 GameManager / DataManager / AudioManager
│   ├── Player             # 玩家控制、相机、动画逻辑
│   ├── FarmSystem         # 地块、作物、种植逻辑
│   ├── InventoryShop      # 背包、商店交易逻辑
│   ├── TimeSystem         # 昼夜时间系统
│   ├── UI                 # 全部UI面板脚本
│   └── SceneSwitch        # 场景切换触发器脚本
├── ScriptableObjects      # 种子、商品配置数据文件
├── Sprites                # 像素美术资源：角色、瓦片地图、UI图标
├── Audio                  # BGM与各类音效
└── Settings               # URP、输入系统配置
```
